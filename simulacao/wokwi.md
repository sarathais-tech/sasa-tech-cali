# Simulação do Cali no Wokwi

Projeto compartilhado: https://wokwi.com/projects/478231749554255873

Esta é a referência indicada pela criadora para a simulação do Cali. A cópia do firmware neste repositório foi reconstruída a partir da versão V0.6 discutida no desenvolvimento. **Ainda não foi feita uma comparação automática com os arquivos originais do projeto Wokwi.**

Para verificar a reprodução, precisamos conferir os arquivos `sketch.ino`, `diagram.json` e `libraries.txt` do Wokwi e executar o projeto.
